# POKECARD Brasil 4.0.2 — Price Database exclusivo

## Alteração principal

- O aplicativo não consulta mais a Liga Pokémon para obter preços.
- A única fonte automática de preço é o repositório `pokemon-price-database`.
- Quando uma variação não existe no banco, ela permanece sem preço automático.
- Preços antigos salvos da Liga são descartados na primeira abertura desta versão.
- O banco continua separando ID, idioma, edição, carimbo e acabamento.

## Publicação

- `versionCode 75`
- `versionName 4.0.2`
- O `applicationId` e a assinatura permanecem inalterados.
